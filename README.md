# My Deen — ফ্রি ইসলামিক অ্যাপ

**My Deen** — নামাজের সময়, কুরআন, তাসবিহ, দোয়া, কিবলা ও রোজা। সম্পূর্ণ ফ্রি, কোনো বিজ্ঞাপন নেই, কোনো অ্যাকাউন্ট নেই।

## ফিচার (v2.0)
- আজকের ৫ ওয়াক্ত নামাজের সময় + লাইভ কাউন্টডাউন (Aladhan API, ডিফল্ট JAKIM মালয়েশিয়া পদ্ধতি, হানাফী আসর)
- হাইপার-রিয়েলিস্টিক আকাশ থিম — সময় অনুযায়ী ভোর/দিন/সোনালি বিকেল/সন্ধ্যা/রাতের আকাশ (তারা ও চাঁদসহ)
- হিজরি + ইংরেজি + বাংলা তারিখ; সেহরি/ইফতার + কাউন্টডাউন; তাহাজ্জুদ, ইশরাক, দুহা, জাওয়াল, আওয়াবিন
- সালাতের নিষিদ্ধ সময় (সকাল/দুপুর/সন্ধ্যা)
- নামাজের হিসাব (ট্র্যাকার) — ৭ দিন ও মাসের হিসাব
- পুরো কুরআন: ১১৪ সূরা, আরবি + বাংলা অনুবাদ, বুকমার্ক, ৮ জন কারির অডিও + **কুরআন ট্র্যাকার** (খতমের অগ্রগতি %)
- ডিজিটাল তাসবিহ (লক্ষ্য ৩৩/৯৯/১০০/৫০০/১০০০)
- দোয়া ও আজকার (২৪টি সহিহ দোয়া) + রুকইয়াহ
- কিবলা কম্পাস (ইপোহ থেকে ২৯১.৯°)
- সুন্নত রোজার রিমাইন্ডার (সোম/বৃহস্পতি, আইয়ামে বীজ, আরাফা) + হিজরি ক্যালেন্ডার
- **নোটিফিকেশন ফিড** — প্রতিদিন একটি সহিহ হাদিস (আরবি + বাংলা + সূত্র) ও একটি আমলের পরামর্শ
- **ব্যাকগ্রাউন্ড আজান (Android)** — প্রত্যেক ওয়াক্তে নোটিফিকেশনে আজান; নোটিফিকেশন কেটে দিলে আজান বন্ধ; আজানের ৫ মিনিট পর "নামাজ পড়েছো কিনা?" (হ্যাঁ/না); না বললে প্রতি ৫ মিনিটে রিমাইন্ডার; উত্তর না দিলে ১৫ মিনিট পর পুরুষ কণ্ঠে "তাড়াতাড়ি নামাজ পড়ে নে" ভয়েস রিমাইন্ডার; প্রত্যেক ওয়াক্তের আজান আগে-পরে করার সেটিং (-৩০ থেকে +৩০ মিনিট); আজানের বার্তায় মিসওয়াক ও অজুর স্মরণ
- **রিয়েল-টাইম লোকেশন** — অনুমতি দিলে GPS থেকে শহর স্বয়ংক্রিয়ভাবে সেট হয়; হাতে শহর লিখেও চালানো যায়
- **ঐচ্ছিক প্রোফাইল** — নাম দিলে শুধু ফোনে থাকে; লগইন ছাড়াই সব ফিচার চলে
- সেটিংস: শহর, হিসাবের পদ্ধতি, মাজহাব, ভাষা (বাংলা/English), থিম, আজান — নিচের মেনু থেকে

## ফোল্ডার
- `index.html`, `styles.css`, `app.js`, `data/duas.js` — PWA ওয়েব অ্যাপ
- `manifest.json`, `sw.js` — ইনস্টল + অফলাইন
- `icons/` — 512×512 আইকন (আসল ডিজাইন, সবুজ + সোনালি)
- `audio/azan.mp3` — আলাফাসির আজান (বান্ডল করা)
- `privacy.html` / `PRIVACY.md` — গোপনীয়তা নীতি
- `play-store/PLAY_STORE_LISTING.md` — প্লে স্টোরের লেখা
- `tests/test-apis.js` — API যাচাই (node tests/test-apis.js) — ১৯/১৯ পাস
- `android/` — Capacitor Android প্রজেক্ট (APK/AAB বানানোর জন্য)

## PWA চালানো (ফোনে)
1. লাইভ লিংক খুলুন
2. Chrome মেনু (⋮) → "Add to Home screen" / "অ্যাপ ইনস্টল করুন"
3. হোম স্ক্রিনের আইকনে চাপ দিলেই অ্যাপ চলবে

## Android APK / AAB বানানো
দেখুন `android/` ফোল্ডার। সংক্ষেপে (Linux/PC):
```
cd android
./gradlew assembleDebug        # debug APK
./gradlew bundleRelease        # release AAB (সাইন করা)
```
Release সাইনের জন্য keystore আছে `android/deen-day-release.keystore` — পাসওয়ার্ড `android/keystore.properties`-এ। **keystore হারাবেন না** — হারালে প্লে স্টোরে আর আপডেট দেওয়া যাবে না। নতুন করে সাইন করতে চাইলে:
```
keytool -genkeypair -v -keystore deen-day-release.keystore -alias deenday \
  -keyalg RSA -keysize 2048 -validity 10000
```

## Play Store-এ আপলোড (নিজে করতে হবে)
1. Google Play Console-এ ডেভেলপার অ্যাকাউন্ট খুলুন — এককালীন **$25** (Google-কে দিতে হয়)
2. "Create app" → নাম: My Deen → `play-store/PLAY_STORE_LISTING.md`-এর লেখা বসান
3. Release AAB (`deen-day-release.aab`) আপলোড করুন, স্ক্রিনশট দিন, Privacy Policy লিংক দিন (privacy.html হোস্ট করে)
4. Review-এর পর প্রকাশ হবে। আপলোড শুধু আপনার নিজের Google অ্যাকাউন্ট থেকেই করতে হবে।

## সৎ সীমা
- ওয়েব অ্যাপ (PWA) ফোন বন্ধ থাকলে ব্যাকগ্রাউন্ডে আজান বাজাতে পারে না — অ্যাপ খোলা থাকলে আজান বাজে। ব্যাকগ্রাউন্ড আজান শুধু নেটিভ Android অ্যাপে (local notifications) সম্ভব। এই VM থেকে আসল ফোনে ব্যাকগ্রাউন্ড আজান পরীক্ষা করা যায়নি — APK ইনস্টল করে অ্যাপ বন্ধ রেখে পরীক্ষা করতে হবে।
- কিছু Android ফোনে নোটিফিকেশনের সাউন্ড সিস্টেমের সীমায় লম্বা আজান (৩.৫ মিনিট) কেটে যেতে পারে; নোটিফিকেশন কেটে দিলে সাউন্ড বন্ধ হয় (সিস্টেমের আচরণ)।
- "নামাজ পড়েছো কিনা?"-র হ্যাঁ/না বোতামের কাজ অ্যাপ চালু হলে কার্যকর হয়; নোটিফিকেশন নিজে অ্যাপ বন্ধ থাকলেও বাজে।
- ভয়েস রিমাইন্ডারের কণ্ঠ TTS দিয়ে তৈরি পুরুষ কণ্ঠ; বাংলা উচ্চারণ নিখুঁত নাও হতে পারে।
- GPS অবস্থান শুধু অনুমতি দিলে ব্যবহার হয়; শহরের নাম OpenStreetMap Nominatim থেকে আসে (ইন্টারনেট লাগে) — না পেলে স্থানাঙ্ক দিয়েই সময় বের হয়।
- ঐচ্ছিক প্রোফাইল শুধু ফোনে থাকে — কোনো সার্ভার/ক্লাউড সিঙ্ক নেই।
